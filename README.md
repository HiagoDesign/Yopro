# YoPRO Cheesecake Hero

Implementação em Vite, HTML, CSS e JavaScript puro baseada no frame YoPRO do Figma.

O projeto reutiliza a linguagem de movimento do experimento Nescau: parallax amortecido, entrada escalonada, produto flutuante, ruído animado, ticker e botões magnéticos.

## Rodar localmente

```bash
npm install
npm run dev
```
